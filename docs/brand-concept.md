# 좋은효소 브랜드 컨셉 (기존 홈페이지 기반 정리안)

> 회사에 별도 브랜드 가이드가 없어, **기존 홈페이지(wellzyme.co.kr)에 이미 있는 표현·구조·색**과 공개된 판매 정보만으로 정리했습니다.
> 근거가 없는 내용은 만들지 않았고, 확인이 필요한 항목은 마지막에 따로 적었습니다.

## 1. 근거 (기존 홈페이지에서 찾은 것)

| 단서 | 출처 | 해석 |
|---|---|---|
| "사업자와 소비자 모두의 풍요창조를 지향하는 기업이 되겠습니다." | 메인 슬라이드 문구 | 회사가 직접 쓴 유일한 비전 문장 → **회사 슬로건** |
| 브랜드 스토리 > 발효 효소의 탄생 · 미리안 이야기 | 메뉴 구조 | 브랜드의 두 축 = **발효 효소** + **미리안** |
| 로고의 파랑·연두·노랑·주황 4색 막대 | 로고, 공지사항 구분선 | 회사가 실제로 쓰는 유일한 브랜드 색 → **시그니처 4색** |
| 황금 들판의 나무 → 자연 속 건물 → 노트북 든 사람 | 회사 소개 카드 사진 순서 | 자연 → 회사 → 비즈니스로 이어지는 이야기 |
| 보상플랜 · 판매원 수첩 · 회원혜택 · 비즈니스양식 | 비즈니스 메뉴 | 직접판매 기업, 사업자 성장이 사업의 중심 |
| "인체정화 미리안" (브랜드 사이트명) | wellzyme.modoo.at | 미리안 = 좋은효소의 제품 브랜드 |
| 미리안 클린 · 이너자임 · 슬림 · 알파자임 · 미리안차 | 공개 판매 페이지 | 미리안 제품 라인 5종 |

## 2. 브랜드 구조

```
좋은효소 (회사 · WELLZYME)
 ├─ 미리안 (제품 브랜드)  — 클린 · 이너자임 · 슬림 · 알파자임 · 미리안차
 └─ 비즈니스 (직접판매)   — 보상플랜 · 판매원 수첩 · 회원혜택
```

## 3. 핵심 메시지

- **슬로건 (원문 유지):** 사업자와 소비자 모두의 풍요를 만드는 기업
  - 원문 "풍요창조를 지향하는 기업이 되겠습니다"를 웹 헤드라인 길이로만 다듬음. 의미는 그대로.
- **두 개의 약속**
  1. 소비자에게 — 발효 효소 브랜드 **미리안**
  2. 사업자에게 — 함께 성장하는 **비즈니스**
- **키워드:** 발효 · 효소 · 미리안 · 함께 · 풍요

## 4. 시각 요소

| 요소 | 규칙 |
|---|---|
| 시그니처 4색 | 로고 막대 색 그대로 `#0091FF` `#8BDB10` `#FFCB44` `#FF6230` — **가는 띠·작은 표식에만** 사용 (면을 칠하지 않음). 순서는 로고와 같게 파랑→연두→노랑→주황 |
| 4색 띠 위치 | 섹션 라벨 앞 표식, 공지사항 상단 구분선(기존 사이트 구성요소 복원), 푸터 상단 |
| 기본 톤 | 흰 바탕 + 잉크색 글자 (Airtable 에디토리얼 시스템). 시그니처 카드(포레스트·코랄·크림·다크)는 그대로 |
| 서체 | Pretendard 한 가지 |

## 5. 문구 작성 원칙 (건강기능식품 표시·광고 주의)

- 제품 효능·기능 문구는 **식약처 인정 기능성 표시 범위 안에서만** 사용 (예: 미리안 클린 — "배변활동 원활에 도움을 줄 수 있음", 판매 페이지 표시 기준).
- "인체정화", "디톡스", "독소 배출", "질병 예방·치료" 같은 표현은 사이트 카피에 직접 쓰지 않음. 회사가 심의받은 문구가 있으면 그 문구로 교체.
- 회사 소개·비즈니스 문구는 과장 없이 사실 위주로.

## 6. 확인이 필요한 항목

- [ ] 슬로건을 원문 그대로("풍요창조를 지향하는 기업이 되겠습니다") 쓸지, 다듬은 표현을 쓸지
- [ ] 미리안 제품 5종이 현재도 판매 중인지, 추가·단종 제품이 있는지
- [ ] 제품별 분류(건강기능식품 / 일반식품)와 심의받은 기능성 문구
- [ ] "미리안" 이름의 의미·탄생 배경 (미리안 이야기 페이지 원고)
- [ ] 로고 원본 파일과 4색의 정확한 색값
