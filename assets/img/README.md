# 사진 넣는 곳

아래 파일명 그대로 이 폴더에 넣으면 해당 자리에 자동으로 표시됩니다.
파일이 없으면 빈 이미지 자리(IMAGE)로 남습니다.

| 파일명 | 들어가는 곳 | 권장 크기 (가로×세로) | 추천 내용 |
|---|---|---|---|
| `hero-01.jpg` | 메인 슬라이드 1 · BRAND STORY | 2400×1080 | 발효 과정, 원료 |
| `hero-02.jpg` | 메인 슬라이드 2 · EVENT | 2400×1080 | 이벤트·제품 |
| `hero-03.jpg` | 메인 슬라이드 3 · WELLZYME | 2400×1080 | 회사·사옥·팀 |
| `hero-04.jpg` | 메인 슬라이드 4 · BUSINESS | 2400×1080 | 사업자 교육·행사 |
| `about-company.jpg` | 메인 회사 소개 초록 카드 | 1600×1000 | 원료 들판, 자연 |
| `popup.jpg` | 팝업 공지 | 800×600 | 이벤트 배너 |
| `company-main.jpg` | 회사소개 > 좋은효소 | 2400×1030 | 회사 대표 이미지 |
| `ceo.jpg` | 회사소개 > CEO 인사말 | 1200×1500 | 대표이사 사진 |

- 형식: JPG (용량 500KB 이하 권장). PNG·WebP를 쓰려면 `assets/js/api.js`와 각 HTML의 경로 확장자만 바꾸면 됩니다.
- 사진은 자리 크기에 맞춰 자동으로 잘려 보이므로, 중요한 피사체는 가운데에 두세요.
