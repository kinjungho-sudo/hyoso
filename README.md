# 좋은효소 홈페이지 리뉴얼 — 메인 페이지

㈜좋은효소(wellzyme.co.kr) 홈페이지 리뉴얼 시안입니다. 기존 메인의 구성요소는 그대로 유지하고, 디자인·반응형·접근성을 새로 만들었습니다. 기존 사이트 분석은 [`docs/design-analysis.md`](docs/design-analysis.md)에 있습니다.

## 보는 법

빌드 과정이 없는 정적 페이지입니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 구조

```
index.html                       메인
회사소개    company · ceo · history · ci · location
브랜드 스토리 story · mirian
비즈니스    business · plan · handbook · benefit · forms(#tax #edu-guide #docs) · edu
공지사항    notice · notice-view(?id=) · delivery · return · installment · privacy · terms · archive
고객센터    branch · committee · gallery · video
assets/css/style.css             디자인 토큰 + 전체 스타일 (반응형 포함)
assets/js/layout.js              공통 헤더·푸터·퀵메뉴 렌더링 (<div data-layout="header|footer">)
assets/js/api.js                 데이터 레이어 — 현재 목업, DB 연동 시 여기만 교체
assets/js/common.js              모든 페이지 공통 동작 (검색, 전체메뉴, 장바구니, 법정 조회 팝업, 스크롤 등장)
assets/js/home.js                메인 전용 (슬라이더, 공지, 팝업 공지)
assets/js/board.js               게시판 렌더링 ([data-board] 공지 목록·상세·자료실·갤러리·영상·본부/센터)
assets/img/                      사진 넣는 곳 (README에 파일명 안내)
docs/                            기존 사이트 분석 문서
```

새 페이지는 `<body data-section="…" data-page="…">`로 현재 위치를 지정하고, 헤더·푸터 자리에 `data-layout` div만 두면 됩니다.

## 디자인 시스템 (Airtable 에디토리얼 + 고급화 레이어)

- **캔버스:** 흰 바탕 + 잉크 `#181d26` 타입 + 넉넉한 여백(섹션 120px). 그라데이션·장식 그림 없음
- **시그니처 카드:** 포레스트 `#0a2e0e` · 코랄 `#aa2d00` · 다크 `#181d26` · 크림 `#f3ebdd`
- **이용 안내 카드:** 원색 파스텔 대신 차분한 뉴트럴 톤(샌드 · 세이지 · 미스트 · 스톤)
- **버튼 페어:** 기본 = 잉크 배경 흰 글씨 + 화살표, 보조 = 흰 배경 + 헤어라인. 인라인 링크만 블루 `#1b61c9`
- **타입:** Pretendard 한 가지. 제목 500, 자간 좁게(-0.025~-0.035em), 섹션마다 작은 영문 라벨(ABOUT · TRUST · NEWS)
- **디테일:** 헤더 스크롤 시 반투명 블러, 카드 호버 시 살짝 떠오름, 스크롤 등장 효과(모션 줄이기 설정 시 꺼짐), 다크 푸터
- **목적:** 회원가입 (내비 · 히어로 · 최종 CTA)

|---|---|---|---|
| 관리자 배너 | 잉크 | 배너가 등록됐을 때만 노출 | ② 배너 슬롯 |
| 내비 (64px) | 흰색(스크롤 시 블러) | 로고(=홈페이지) · GNB · 검색 · 장바구니(수량·금액) · 로그인 · 쇼핑몰 · **회원가입** · 전체메뉴 | ① ② ③ |
| 히어로 | 흰색 | 헤드라인 + 버튼 페어 / 아래 메인 비주얼 슬라이더 | ④ |
| ABOUT | 시그니처 카드 | 포레스트(회사) · 코랄(브랜드 스토리) · 크림(비즈니스) | ⑤ |
| TRUST | 크림 밴드 | 등록 · 080 · 법정 조회 3종 + 이용 안내 카드 4개 | ⑥ |
| NEWS | 흰색 | 공지 4건 | ⑦ |
| 회원혜택 | 다크 카드 | 보상플랜 · 회원혜택 · 교육자료 | — |
| 최종 CTA | 웜 그레이 밴드 | 회원가입 | — |
| 푸터 | 잉크 다크 | 법정 고지 링크 · 로고 · 사업자 정보 원본 유지 | ⑧ |
| 퀵메뉴 | — | 1480px↑ 우측 고정 · 1025–1479px 우하단 버튼 · 1024px↓ 하단 탭바 | ⑨ |
| 팝업 공지 · 로딩 바 | — | 오늘 하루 보지 않기 / 느린 요청 시 상단 진행 바 | 팝업 · 로딩 바 |

기존 구성요소 중 공지사항 위 **4색 구분선(로고 레인보우)** 만 의도적으로 제외.

- 브레이크포인트: 1024px (태블릿), 767px (모바일)

## DB 연동 시 교체할 곳

`assets/js/api.js`의 각 함수만 바꾸면 됩니다. 요청을 `track()`으로 감싸면 300ms 넘게 걸릴 때 전역 로딩 바(원본 `#loadingBar`)가 자동으로 표시됩니다.

| 함수 | 데이터 |
|---|---|
| `getSession()` | 로그인 사용자 |
| `getTopBanner()` | 관리자 배너 (원본 `#bannerCntsPc`, 없으면 숨김) |
| `getCart()` | 장바구니 수량·금액 |
| `getSlides()` | 메인 비주얼 오른쪽 이미지 슬라이드 (라벨·제목·링크·이미지) |
| `getNotices()` | 공지사항 최근 4건 |
| `getPopups()` | 팝업 공지 |
| `getNoticeList()` · `getNotice(id)` | 공지 목록(검색·페이지는 현재 화면에서 처리 → DB 연동 시 쿼리로) · 상세(이전/다음 글) |
| `getArchive()` | 자료실 파일 목록 |
| `getGallery()` · `getVideos()` | 사진갤러리 · 행사영상 |
| `getBranches()` | 본부/센터 목록 |
| `noticeUrl(id)` | 공지 상세 경로 |
| `popupUrls` | 보증서조회·평균후원수당·판매원조회 팝업 경로 (원본 URL 확인 필요) |

## 남은 작업

- 사진: `assets/img/README.md`의 파일명대로 넣으면 자동 표시 (없으면 빈 자리 유지). 로고는 `layout.js`의 TODO 자리에 교체
- 회사소개 하위 페이지의 문구(가치·CEO 인사말·연혁)는 시안용 예시 → 회사 원고로 교체
- 하위 페이지 원고: 브랜드 스토리·미리안·보상플랜·판매원 수첩·회원혜택 문구는 시안용 예시, 주문/배송·반품·개인정보·약관은 기존 사이트 원문 이관 필요
- 다운로드 파일(양식·교육자료·수첩): 파일을 받으면 각 '다운로드' 버튼에 연결
- 쇼핑몰·주문·회원가입·로그인(`/shop`, `/order`, `/member`, `/login`)은 기존 MyOffice 시스템 경로 그대로 연결
- 오시는 길 지도: 카카오맵/네이버 지도 API 키 발급 후 연결
