# 좋은효소 홈페이지 리뉴얼 — 메인 페이지

㈜좋은효소(wellzyme.co.kr) 홈페이지 리뉴얼 시안입니다. 기존 메인의 구성요소는 그대로 유지하고, 디자인·반응형·접근성을 새로 만들었습니다. 기존 사이트 분석은 [`docs/design-analysis.md`](docs/design-analysis.md)에 있습니다.

## 보는 법

빌드 과정이 없는 정적 페이지입니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 구조

```
index.html              메인
company.html            회사소개 > 좋은효소
ceo.html                회사소개 > CEO 인사말
history.html            회사소개 > 연혁
ci.html                 회사소개 > CI
location.html           회사소개 > 오시는 길
assets/css/style.css    디자인 토큰 + 전체 스타일 (반응형 포함)
assets/js/layout.js     공통 헤더·푸터·퀵메뉴 렌더링 (<div data-layout="header|footer">)
assets/js/api.js        데이터 레이어 — 현재 목업, DB 연동 시 여기만 교체
assets/js/common.js     모든 페이지 공통 동작 (검색, 전체메뉴, 장바구니, 법정 조회 팝업)
assets/js/home.js       메인 전용 동작 (슬라이더, 공지, 팝업 공지)
docs/                   기존 사이트 분석 문서
```

새 페이지는 `<body data-section="…" data-page="…">`로 현재 위치를 지정하고, 헤더·푸터 자리에 `data-layout` div만 두면 됩니다.

## 디자인 시스템 (프리미엄 에디토리얼)

구조는 Airtable 에디토리얼 시스템(버튼 페어 · 시그니처 카드 · 섹션 리듬)을 따르고, 톤은 프리미엄 웰니스 브랜드로 올림.

- **색:** 포레스트 딥 `#0d1f13` · 잉크 `#181d26` / 본 캔버스 `#f7f3ec` · 크림 `#f5e9d4` / 코랄 `#aa2d00`(강조 1곳) / 황동 `#b9965f`(헤어라인·숫자 장식 전용)
- **서체 3종:** 제목 Hahmlet 200–300 · 라틴 이탤릭 포인트(로고 영문·숫자·챕터) Cormorant Garamond · 본문 Pretendard
- **형태:** 사각 엣지 버튼·카드 + 아치 프레임으로 곡선 대비, 황동 1px 이중 프레임
- **질감·움직임:** 다크 섹션에 종이 그레인, 흐르는 문구 띠, 스크롤 등장, 슬라이드 천천히 확대(모션 줄이기 설정 시 모두 꺼짐)
- **이미지 자리:** 회색 박스 대신 '발효의 물결' 추상 아트(`.art--moss/coral/cream/amber`). 실제 사진은 `<img>`로 교체하거나 슬라이드는 `api.js`의 `image.src`만 채우면 됨
- **헤더:** 다크 히어로 위에서는 히어로와 같은 색 → 스크롤하면 본 캔버스로 전환
- **목적:** 회원가입 (헤더 · 히어로 · 멤버십 섹션)

| 섹션 | 바탕 | 내용 | 기존 구성요소 |

| 히어로 | 포레스트 딥 | 대형 세리프 카피 + 버튼 페어 / 아치 프레임 슬라이더(번호 페이저) | ④ |
| 문구 띠 | 본 | Natural Ingredients · Slow Fermentation … | — |
| No.01 철학 | 본 | 브랜드 선언 | — |
| No.02 회사 소개 | 본 | 회사 · 브랜드 스토리 · 비즈니스 — 이미지·텍스트 교차 | ⑤ |
| No.03 신뢰 | 잉크 다크 | 2013 · 080 · 법정 조회 03 + 이용 안내 4행 | ⑥ |
| No.04 공지 | 본 | 최근 4건 | ⑦ |
| No.05 멤버십 | 크림 카드 | 회원가입 CTA + 보상플랜 · 회원혜택 · 교육자료 | — |
| 푸터 | 잉크 다크 | 법정 고지 링크 · 로고 · 사업자 정보 원본 유지 | ⑧ |
| 퀵메뉴 | — | 1480px↑ 우측 고정 · 1025–1479px 우하단 버튼 · 1024px↓ 하단 탭바 | ⑨ |
| 팝업 공지 · 로딩 바 | — | 오늘 하루 보지 않기 / 느린 요청 시 상단 진행 바 | 팝업 · 로딩 바 |

기존 구성요소 중 공지사항 위 **4색 구분선(로고 레인보우)** 만 의도적으로 제외.

- 브레이크포인트: 1024px (태블릿), 767px (모바일)

## DB 연동 시 교체할 곳

`assets/js/api.js`의 각 함수만 바꾸면 됩니다. 요청을 `track()`으로 감싸면 300ms 넘게 걸릴 때 전역 로딩 바(원본 `#loadingBar`)가 자동으로 표시됩니다.

| 함수 | 데이터 |
|---|---|
| `getSession()` | 로그인 사용자 |
| `getTopBanner()` | 관리자 배너 (원본 `#bannerCntsPc`, 없으면 숨김) |
| `getCart()` | 장바구니 수량·금액 |
| `getSlides()` | 메인 비주얼 오른쪽 이미지 슬라이드 (라벨·제목·링크·이미지) |
| `getNotices()` | 공지사항 최근 4건 |
| `getPopups()` | 팝업 공지 |
| `noticeUrl(id)` | 공지 상세 경로 |
| `popupUrls` | 보증서조회·평균후원수당·판매원조회 팝업 경로 (원본 URL 확인 필요) |

## 남은 작업

- 로고·사진·일러스트: 현재 플레이스홀더(`.ph`) → 고객사 원본 자산으로 교체. 슬라이드는 `api.js`의 `image.src`만 채우면 됨
- 회사소개 하위 페이지의 문구(가치·CEO 인사말·연혁)는 시안용 예시 → 회사 원고로 교체
- 아직 만들지 않은 하위 페이지 링크는 기존 사이트 경로(`/info/osStory` 등) 그대로 → 페이지 제작 시 교체
- 오시는 길 지도: 카카오맵/네이버 지도 API 키 발급 후 연결
