# 좋은효소 홈페이지 리뉴얼 — 메인 페이지

㈜좋은효소(wellzyme.co.kr) 홈페이지 리뉴얼 시안입니다. 기존 메인의 구성요소는 그대로 유지하고, 디자인·반응형·접근성을 새로 만들었습니다. 기존 사이트 분석은 [`docs/design-analysis.md`](docs/design-analysis.md)에 있습니다.

## 보는 법

빌드 과정이 없는 정적 페이지입니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 구조

```
index.html            메인 페이지 마크업
assets/css/style.css  디자인 토큰 + 전체 스타일 (반응형 포함)
assets/js/api.js      데이터 레이어 — 현재 목업, DB 연동 시 여기만 교체
assets/js/main.js     인터랙션 (슬라이더, 전체메뉴, 공지, 팝업 등)
docs/                 기존 사이트 분석 문서
```

## 기존 구성요소 대응

| 기존 | 리뉴얼 |
|---|---|
| ① Top Bar (홈페이지·로그인·신규가입) | PC 상단 유틸 바 / 모바일은 전체메뉴 안으로 |
| ② 로고·검색·장바구니 | 헤더 한 줄로 통합, 모바일은 검색 아이콘 → 펼침 |
| ③ 아이콘 메뉴 6칸 + 전체보기 | 텍스트 GNB + `전체메뉴` 버튼 (PC 드롭다운 / 모바일 전체화면 아코디언) |
| ④ 메인 비주얼 (이미지에 카피 합성) | 카피를 HTML 텍스트로 분리, 진행바·정지 버튼·스와이프 |
| ⑤ 회사 소개 카드 3 (더미 문구) | 실제 문구 작성, 제목↔설명 매핑 정리, 모바일 가로 스크롤 |
| ⑥ 서비스 아이콘 카드 4 (더미 문구) | 번호형 리스트 카드 |
| ⑦ 공지사항 | 2단 레이아웃, `api.getNotices()`로 렌더링 |
| ⑧ 푸터 (법정 고지 링크·사업자 정보) | 내용 원본 그대로 유지 |
| ⑨ 우측 고정 퀵메뉴 | PC 우측 고정 / 태블릿·모바일 하단 탭바 |
| 팝업 공지 (오늘 하루 안 보기) | 모달 + localStorage |

## 디자인 토큰

- 색: 딥 그린 `#2E4A36` (브랜드) + 아이보리 `#FAF8F3` / 잉크 `#191B17` (뉴트럴)
- 폰트: 제목 Noto Serif KR, 본문 Pretendard
- 브레이크포인트: 1080px (태블릿), 720px (모바일)

## DB 연동 시 교체할 곳

`assets/js/api.js`의 각 함수만 바꾸면 됩니다.

| 함수 | 데이터 |
|---|---|
| `getSession()` | 로그인 사용자 |
| `getCart()` | 장바구니 수량·금액 |
| `getSlides()` | 메인 비주얼 슬라이드 |
| `getNotices()` | 공지사항 최근 4건 |
| `getPopups()` | 팝업 공지 |
| `noticeUrl(id)` | 공지 상세 경로 |
| `popupUrls` | 보증서조회·평균후원수당·판매원조회 팝업 경로 (원본 URL 확인 필요) |
